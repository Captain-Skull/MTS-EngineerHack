# 0002. Kubernetes 1.36, а не последняя 1.37

Статус: принято.

## Контекст

Последняя версия Kubernetes сейчас 1.37. Но сеть и шлюз здесь критичны: если они не поддерживают версию кластера, перестаёт работать весь входящий трафик.

## Решение

Взят Kubernetes 1.36.5. Это самая новая версия, которую официально поддерживают и Cilium 1.20, и Envoy Gateway 1.9 (оба тестируются на версиях с 1.33 по 1.36). Версия закреплена в [`ansible/group_vars/all.yml`](../../ansible/group_vars/all.yml).

## Альтернативы

- 1.37 новее, но не входит в матрицы совместимости Cilium и Envoy Gateway. Можно получить неочевидные ошибки как раз в тех компонентах, которые проверяет кейс.
- 1.35 поддерживают все компоненты, включая Kyverno, но тогда без всякой причины отстаём на версию.

## Последствия

- Kyverno 1.19 официально тестируется на версиях с 1.33 по 1.35. Что он работает на 1.36, подтверждают наши e2e и smoke-тесты на каждом коммите; в README это вынесено в известные ограничения.
- На 1.37 можно будет перейти вручную, когда Cilium и Envoy Gateway выпустят версии с её поддержкой.
