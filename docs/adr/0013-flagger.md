# 0013. Progressive delivery: Flagger с провайдером Gateway API

**Статус:** принято

## Контекст

Canary у `hello` ручной: вес 90/10 записан в values. Новая версия получает трафик сразу, а решение «продвигать или откатывать» принимает человек по графикам. Не хватает автоматической проверки новой версии на части трафика.

## Решение

**Flagger 1.45** с провайдером `gatewayapi:v1`. Он управляет отдельным демо-сервисом `rollout.demo.test` ([`charts/rollout`](../../charts/rollout), podinfo): сам создаёт `HTTPRoute` и сервисы `-primary`/`-canary`, по шагам меняет веса (20/40/60%) и проверяет собственные `MetricTemplate` в Prometheus — долю 5xx и p99 новой версии. Три неудачные проверки — автоматический откат.

`hello` с ручным canary (90/10, `X-Canary`, `/v1` `/v2`) оставлен без изменений: он показывает возможности Gateway API в статике, `rollout` — автоматизацию поверх них.

## Альтернативы

- **Argo Rollouts** — заменяет Deployment своим ресурсом `Rollout`; пришлось бы переписать чарты, интеграция с Gateway API через плагин.
- **Метрики Envoy вместо метрик приложения** — Envoy Gateway объединяет backend одного правила `HTTPRoute` в один кластер, и ошибки canary нельзя отделить от ошибок стабильной версии. Поэтому анализ строится на метриках самого приложения с фильтром по подам canary.
- **Ручное продвижение** — уже есть у `hello`; не защищает от человеческой ошибки и медленной реакции.

## Последствия

- Неисправная версия затрагивает только долю трафика canary и только до отката (около минуты): в тесте 4,4% запросов за время анализа и 0 после.
- Анализу нужен трафик: без запросов метрик нет, и Flagger считает проверку неудачной. `make rollout` создаёт нагрузку сам; в production трафик даёт реальный пользователь или webhook-нагрузка Flagger (loadtester).
- Изменение через `kubectl` создаёт расхождение с Git: следующий `make platform` вернёт версию из Git — тоже через анализ Flagger. Естественный следующий шаг — изменение версии коммитом и синхронизация GitOps-контроллером.
- Плюс два небольших компонента: контроллер Flagger и сам сервис (около 60 МБ памяти).
