# 0013. Progressive delivery: Flagger с провайдером Gateway API

Статус: принято.

## Контекст

У `hello` canary ручной: вес 90/10 записан в values. Новая версия сразу получает свою долю трафика, а продвигать её или откатывать, решает человек, глядя на графики. Автоматической проверки новой версии на части трафика не было.

## Решение

Flagger 1.45 с провайдером `gatewayapi:v1`. Он управляет отдельным демо-сервисом `rollout.demo.test` ([`charts/rollout`](../../charts/rollout), приложение podinfo). Flagger сам создаёт `HTTPRoute` и сервисы `-primary` и `-canary`, по шагам меняет веса (20, 40, 60%) и проверяет свои `MetricTemplate` в Prometheus: долю 5xx и p99 новой версии. После трёх неудачных проверок он откатывает выкатку.

`hello` с ручным canary (90/10, `X-Canary`, `/v1` и `/v2`) остался как был. Он показывает возможности Gateway API в статике, а `rollout` показывает автоматизацию поверх них.

## Альтернативы

- Argo Rollouts заменяет Deployment своим ресурсом `Rollout`. Пришлось бы переписать чарты, а с Gateway API он работает через плагин.
- Можно было бы анализировать метрики Envoy, но Envoy Gateway объединяет все backend одного правила `HTTPRoute` в один кластер, и ошибки canary там не отличить от ошибок стабильной версии. Поэтому анализ строится на метриках самого приложения с фильтром по подам canary.
- Ручное продвижение уже есть у `hello`. От ошибки человека и медленной реакции оно не защищает.

## Последствия

- Неисправная версия задевает только долю трафика canary и только до отката, а это около полутора минут. В тесте ошибки получили 4,9% запросов за время анализа и ни одного после.
- Анализу нужен трафик. Без запросов нет метрик, и Flagger засчитывает проверку как неудачную. `make rollout` создаёт нагрузку сам, в production её дают пользователи или loadtester Flagger.
- Версию меняют через Git и Argo CD ([0014](0014-gitops-argocd.md)). Правка Deployment через `kubectl` бесполезна: Argo CD вернёт состояние из Git.
- Добавилось два небольших компонента, контроллер Flagger и сам сервис, вместе около 60 МБ памяти.
